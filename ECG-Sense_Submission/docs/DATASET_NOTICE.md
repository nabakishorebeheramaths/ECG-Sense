# Dataset Notice

## MIT-BIH Arrhythmia Database

ECG-Sense was evaluated using records from the MIT-BIH Arrhythmia Database distributed through PhysioNet.

The original ECG dataset is intentionally not duplicated inside this submission package.

This keeps the submission lightweight and avoids redistributing the original dataset unnecessarily.

### Reproducibility

To reproduce the experiments, obtain the required MIT-BIH records from the appropriate PhysioNet source and place them in the local data/mitdb directory used by the MATLAB WFDB tools.

The submission package contains the complete ECG-Sense processing, evaluation, documentation, results, and figures.
